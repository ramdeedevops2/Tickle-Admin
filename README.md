## Instagram account search

The Read a Website screen uses Tavily Search to find Instagram profile URLs by name. It tries to omit creator and business accounts when Tavily's public title or snippet contains category or bio signals. This is a best-effort guess, not account verification, and the screen returns URLs only. Add `TAVILY_API_KEY` to the admin server environment; get a key from [Tavily](https://app.tavily.com/home). Keep the key server-side and do not use a `NEXT_PUBLIC_` variable.

The search is restricted to `instagram.com` and India. Search results may include unrelated or outdated accounts, so verify each URL before using it.
